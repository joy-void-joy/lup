# What's published

What's committed, pushed or posted goes out under the operator's name, and this room shows you the host's real paths. So write a path in this repository from its root, another repository by its name, and anything else in the operator's home with `~` (`~/.config/lup/`), and leave out the operator's user name, the host's name and an SSH alias in a remote. lup keeps a list of the operator's private values on the host, which you never see:
- **a write** carrying one is told to you right after it, as a rule's finding is, and flagged for the operator;
- **the gate's `private` step** fails on one in the files, or in a commit the remotes lack;
- **a push or a post** carrying one is refused, saying where. A push sends every commit the remote lacks, so rewrite the commit that added one (amend it, or rebase) rather than fixing it on top.
